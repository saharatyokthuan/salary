# ♻️ บันทึกเงินเดือน

เว็บแอปบันทึกสลิปเงินเดือนส่วนตัว ทำงานบนเบราว์เซอร์ล้วน ๆ (HTML + CSS + JavaScript) เก็บข้อมูลในเครื่องผ่าน `localStorage`

---

## ✨ ฟีเจอร์หลัก

| แท็บ / ส่วน | ความสามารถ |
|:---|:---|
| 📝 **บันทึก** | กรอกงวดที่และวันที่จ่าย, เพิ่ม/ลบรายการรับและรายการหัก (เลือกชื่อรายการจาก dropdown พร้อมกรอกจำนวนเงิน), คำนวณ รวมรับ / รวมหัก / เงินได้สุทธิ แบบ real-time |
| 📊 **ยอดสะสม** | คำนวณเงินได้สะสม, ภาษีสะสม, ประกันสังคมสะสม อัตโนมัติภายในปีเดียวกัน (ภาษีและประกันสังคมจับจากรายการหักที่ชื่อมีคำว่า "ภาษี" / "ประกันสังคม") |
| 📜 **ประวัติ** | รายการสลิปทั้งหมดเรียงจากวันที่ใหม่ไปเก่า, กดดูรายละเอียดสลิป, แก้ไข หรือลบ (มีหน้าต่างยืนยันก่อนลบ) |
| 📈 **แนวโน้ม** | สรุปค่าเฉลี่ย / สูงสุด / ต่ำสุดของเงินได้สุทธิ, กราฟเส้นแนวโน้มเงินได้สุทธิ, กราฟแท่งเปรียบเทียบรับ vs หัก (6 งวดล่าสุด) วาดด้วย `<canvas>` |
| 🏷️ **หมวดหมู่** | เพิ่ม / เปลี่ยนชื่อ / ลบชื่อรายการรับและรายการหัก (เปลี่ยนชื่อแล้วอัปเดตสลิปเก่าให้ด้วย), มีหมวดหมู่เริ่มต้นให้ในการเปิดครั้งแรก |
| ⚙️ **ตั้งค่า** | บันทึกข้อมูลส่วนตัว (ชื่อ-สกุล, รหัสพนักงาน, สาขา/หน่วยงาน, เลขบัญชีธนาคาร) ชื่อและสาขาจะแสดงใต้ชื่อแอป |
| 📤 **CSV** | ส่งออกสลิปทั้งหมดเป็นไฟล์ `salary-export-YYYYMMDD.csv` (รวมข้อมูลส่วนตัวที่กรอกไว้ และยอดสะสม, เข้ารหัส UTF-8 พร้อม BOM) |
| 🔄 **Backup / 📥 Input** | สำรองสลิปเป็นไฟล์ `salary-backup-YYYYMMDD.json` และนำเข้าไฟล์ `.json` กลับมารวมกับข้อมูลเดิม (มีหน้าต่างยืนยัน) |

## 📁 โครงสร้างไฟล์

```
salary/
├── index.html    # โครงหน้าเว็บ (แท็บบันทึก/ประวัติ/แนวโน้ม/หมวดหมู่/ตั้งค่า)
├── script.js     # ตรรกะทั้งหมด: บันทึก, คำนวณ, กราฟ, CSV, backup/restore
├── style.css     # สไตล์ (ธีมมืด)
└── README.md     # ไฟล์นี้
```

## 🚀 วิธีใช้งาน

ไม่ต้องติดตั้งหรือ build ใด ๆ เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที — หรือรันผ่าน local server:

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000

ขั้นตอนใช้งานเบื้องต้น:

1. แท็บ **ตั้งค่า** กรอกข้อมูลส่วนตัว (ถ้าต้องการ) แล้วกดบันทึก
2. แท็บ **บันทึก** ระบุงวดที่ วันที่จ่าย เพิ่มรายการรับ/รายการหัก แล้วกด **บันทึก**
3. ดูสลิปที่แท็บ **ประวัติ** และกราฟที่แท็บ **แนวโน้ม**
4. ใช้ปุ่ม **CSV** / **Backup** / **Input** ที่แถบด้านบนเพื่อส่งออกหรือสำรอง/นำเข้าข้อมูล

## 💾 การเก็บข้อมูล

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่มีการส่งขึ้นเซิร์ฟเวอร์ โดยใช้ key ดังนี้

| Key | เนื้อหา |
|:---|:---|
| `salarySlipData_v1` | สลิปเงินเดือนทั้งหมด |
| `salaryProfileData_v1` | ข้อมูลส่วนตัว |
| `salaryItemNames_v1` | รายชื่อหมวดหมู่รายการรับ/รายการหัก |

การล้างข้อมูลเบราว์เซอร์จะลบข้อมูลทั้งหมด ควรกด **Backup** เป็นประจำ

> หมายเหตุ: ไฟล์ Backup บันทึกเฉพาะสลิป (`slips`) ไม่รวมข้อมูลส่วนตัวและรายชื่อหมวดหมู่

---

## 🛠️ เทคโนโลยีที่ใช้

- HTML5, CSS3, Vanilla JavaScript (ไม่มีเฟรมเวิร์ก, ไม่มี build step)
- `<canvas>` สำหรับวาดกราฟ (ไม่ใช้ไลบรารีกราฟ)
- `localStorage` สำหรับเก็บข้อมูลฝั่ง client
- Google Fonts (โหลดผ่าน `@import` ใน `style.css`): Sarabun เป็นฟอนต์หลัก (ต้องใช้อินเทอร์เน็ตเพื่อโหลดฟอนต์)
